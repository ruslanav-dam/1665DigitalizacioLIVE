El contingut prové del repositori privat [`1665Digitalizacio`](https://github.com/ruslanav-dam/1665Digitalizacio). Qualsevol canvi fet aquí es perdrà a la propera execució de `npm run deploy`.

Per fer canvis: edita els fitxers a la carpeta `web/` del repo font, executa `npm run deploy` allà, i fes `git push` aquí.
